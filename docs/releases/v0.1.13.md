## Changes

ContextTrace v0.1.13 adds project organization and native session resume.

- Group temporary working folders under **Temporary workspaces** in the Projects dropdown. Expand individual folders or browse the group together.
- Add reversible **Hide from project list** and **Always show** preferences. They affect the dropdown; session discovery, search and dashboard totals still include those sessions. Missing folders are labelled separately.
- Add **Resume** to each session row. Review/copy the command or open an interactive Windows terminal using `codex resume <id> --cd <folder>` or `claude --resume <id>`. Subagents offer **Resume parent**.
- Recheck original session identity, working folder and installed CLI on launch. A missing temporary folder can be replaced with an existing absolute local folder. Archive-only copies cannot be resumed without the original agent logs.
- Refresh documentation and distinguish saved native context from a new session started with a supplied summary. Resume does not generate or inject a summary; the agent restores its saved conversation and compaction state.

## Requirements and verification limits

The corresponding agent CLI must be installed. Claude lookup across projects depends on its CLI version. A resumed agent may contact its service and write to its own logs/working folder using its configured permissions; ContextTrace sends no prompt automatically.
