## Changes

- Open existing local file targets directly from Context composition. File rows also offer **Show in Explorer** and **Copy path**. Full paths survive shortened labels and repeated spaces; commands, queries and URLs stay plain text.
- Show a clear status for deleted temporary files and paths unavailable on this computer. Relative paths resolve only when the tool call records its working directory.
- Fix notification navigation from every application tab. Findings open the linked Conversation record, load it if needed, expand it and scroll to it; turn-only findings land on the first record for that turn.
- Add Windows toast activation so clicking a new toast restores the running window or launches the installed app and follows the notification. Expired notifications open the feed with an explanation.

## Windows upgrade

Install the v0.1.11 setup executable over the existing installation, or use the in-app updater. The installer registers the notification activation protocol. Portable and development builds do not register it, and old toasts retain their original behavior.

Files open with their current contents using Windows file associations. Common executable and shortcut types offer Explorer instead of direct execution.

Woodpecker validates the source, packages the Windows release and verifies published assets. Separate clean-host installer, updater and actual Windows toast/file-opening acceptance remain unverified.
