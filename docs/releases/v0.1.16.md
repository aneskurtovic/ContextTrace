## Changes

ContextTrace v0.1.16 improves request fidelity, archive recovery, local file handling and session browsing.

- Exclude a request's own response from its prompt snapshot. Claude ancestry cycles are refused before duplicated context grows.
- Preserve acknowledged archive revisions across failed metadata commits. Interrupted manifest tails no longer hide later saves; independent writers are serialized.
- Keep incomplete usage unpriced and omit forecasts when required billing buckets are missing.
- Redact JSON credential members, including escaped keys and values, while preserving unrelated bytes.
- Keep Follow live and cache invalidation working when notification delivery is disabled.
- Offer direct Open only for supported data-file extensions; active and unknown file types remain available through Show in Explorer.
- Compare instruction files through a bounded local regular-file reader, with explicit unsafe-path, oversized-file and non-regular-file refusals.
- Count every Claude tool call/result in supported multi-block records, including a later failed result, without duplicating request usage.
- Keep alerts independent when agents share a session ID, preserving agent-wide format-drift deduplication and migrating retained notification history.
- Keep metadata, Conversation and Save & export accessible when a session has no prompt usage or optional context analysis fails.

## Verification and remaining limits

Local development checks cover 547 Rust tests (one ignored), 187 frontend tests, targeted live/context race regressions, formatting, strict Clippy, the frontend build, 17 fixture entries, validator negative cases and PowerShell 5.1 release-note serialization. Publication evidence is tracked in [MVP status](https://github.com/aneskurtovic/ContextTrace/blob/main/docs/MVP-STATUS.md).

Woodpecker validates the exact main commit and performs Windows tag packaging, publication and uploaded-asset verification. Local checks are not release packaging evidence. Separate clean-host installer/updater, installed toast/file-association behavior, real-agent resume and native visual acceptance remain unverified.

Twelve of the 34 engineering audit findings have remediation checkpoints; [the backlog](https://github.com/aneskurtovic/ContextTrace/blob/main/docs/BACKLOG.md) records remaining work. Context membership is bounded by recorded evidence: exact Codex request identity and aggregated Claude request iterations remain capture limitations. General archive orphan reconciliation remains open. The instruction reader is not race-proof against concurrent ancestor replacement and does not determine Unix mount locality. File-extension policy does not verify the associated Windows reader. Legacy notification tombstones without retained records cannot be attributed reliably; persisted session cursors continue to govern replay. Parser support remains scoped to the compatibility catalog.
