## Changes

ContextTrace v0.1.18 includes the unreleased v0.1.17 changes and fixes release publishing on Windows PowerShell 5.1 when processing nested JSON asset arrays.

- Improve prompt reconstruction, Claude multi-tool accounting, archive recovery, credential redaction and live observation. Restrict direct file opening, bound instruction-file reads and keep sessions browsable when usage data is missing.
- Include Linux desktop development and packaging support, macOS port preparation, content hashing simplification and repository maintenance. Published release assets remain Windows x64 only; Linux release assets are not yet available, and native macOS compilation, launch and installation remain unverified.

See the [v0.1.17 notes](https://github.com/aneskurtovic/ContextTrace/blob/main/docs/releases/v0.1.17.md) for details and retained limitations, including capture fidelity, archive recovery, local-file handling and notification identity.

## Verification and limits

The Woodpecker Windows tag pipeline performs release packaging, publication and uploaded-asset checks. Separate clean-host installer and updater acceptance, native desktop visual and interaction checks, Windows toast and file-association behavior, and real-agent resume remain unverified. Parser compatibility remains scoped to the [fixture catalog and policy](https://github.com/aneskurtovic/ContextTrace/blob/main/docs/FORMAT-COMPATIBILITY.md).
