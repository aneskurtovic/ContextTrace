## Changes

ContextTrace v0.1.14 automatically retrieves model prices from LiteLLM's public pricing catalog.

- Open Spend & Forecast to load prices automatically. The desktop no longer asks for a pricing file.
- Price recorded usage with the catalog revision available at the turn's timestamp, and use current rates for forecasts. Show source revisions and warnings alongside estimates.
- Cache pricing snapshots locally so previously fetched prices remain available offline. ContextTrace downloads public catalogs and revision dates; it does not upload conversations or model names.
- Cover all 11 public model IDs found in the local compatibility audit, including current and first/last observed historical lookups. Internal and synthetic IDs without published prices remain explicitly unpriced, with partial totals clearly marked.
- Account for published input, output, cache and context-tier token rates. CLI/MCP contract price overrides remain optional.

## Requirements and verification limits

Initial price discovery and refresh require access to GitHub's public API and LiteLLM catalog. Historical revisions reflect when LiteLLM recorded a price, which may differ from the provider's effective date. Missing history or required rates remain unpriced. Estimates cover standard text-token API rates, not subscription invoices, negotiated contracts, tool/media fees or nondefault cache durations.

Woodpecker validates the exact main commit before tag packaging, publication and uploaded-asset verification. Separate clean-host installer/updater acceptance and native desktop visual QA remain unverified. Parser compatibility remains scoped to the compatibility catalog.
